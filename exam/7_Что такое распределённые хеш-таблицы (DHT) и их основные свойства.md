# 1) Что такое распределённые хеш-таблицы (DHT) и их основные свойства

**Определение.**
**Distributed Hash Table (DHT)** — распределённая структура данных типа «ключ $\to$ значение», где узлы P2P-сети совместно хранят пары $(\text{key}, \text{value})$ и обеспечивают их поиск/запись без центрального сервера.

**Идея.**

* Ключи и узлы отображаются хеш-функцией в общее идентификаторное пространство (обычно $[0,2^m-1]$).
* Каждый узел отвечает за «свой» диапазон ключей (по правилу протокола).

**Операции.**

* `put(key, value)`: сохранить значение по $key$ на узлах, «близких» к $hash(key)$.
* `get(key)`: найти узлы, ответственные за $hash(key)$, и получить значение.

**Свойства.**

* **Децентрализация:** нет центрального индекса.
* **Масштабируемость:** поиск за $O(\log N)$ шагов при $N$ узлах.
* **Устойчивость:** репликация и переназначение ключей при входе/выходе узлов.
* **Балансировка:** хеширование равномерно распределяет ключи между узлами.
* **Динамичность:** поддержка churn (частых присоединений/отключений).
