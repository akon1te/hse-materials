# Модель Клейнберга: навигационный тесный мир, параметр $r=2$, децентрализованный поиск

## 1) Постановка модели

* Узлы расположены на решётке $n\times n$ (или в $\mathbb{Z}^2$).
* Метрика — манхэттенское расстояние:

  ```math
  d\big((i,j),(k,\ell)\big)=|k-i|+|\ell-j|.
  ```
* У каждого узла есть:

  1. **локальные рёбра** к ближайшим соседям (по решётке);
  2. **дальние рёбра** (long-range links), добавляемые случайно: для любого $u\ne v$

  ```math
  \Pr\big((u,v)\in E\big)\ \propto\ d(u,v)^{-r},
  ```

  где $r\ge 0$ — параметр распределения длин «дальних» связей.

**Цель:** передать сообщение из произвольного узла-источника $s$ к цели $t$, используя **децентрализованный** (локальный) алгоритм — без глобального знания всей сети.

---

## 2) Децентрализованный жадный алгоритм (greedy routing)

На каждом шаге сообщение находится в текущем узле $x$. Оно передаётся тому соседу $u\in \mathcal{N}(x)$, который **наиболее близок к цели** $t$ по метрике $d$:

```math
x \leftarrow \operatorname*{arg\,min}\limits_{u\in \mathcal{N}(x)} d(u,t)
\quad\text{если}\quad d(u,t)<d(x,t);
\quad\text{иначе — остановка.}
```

(В базовой модели предполагается, что локальные и дальние рёбра узла $x$ доступны для выбора.)

---

## 3) Теорема Клейнберга: навигируемость при $r=2$

**Утверждение (идея):** существует децентрализованный алгоритм (в частности, greedy), который при $r=2$ доставляет сообщение от $s$ к $t$ за ожидаемое число шагов

```math
\mathbb{E}[T]\ =\ O\!\big((\log n)^2\big).
```

То есть сеть является **навигационным тесным миром**: короткие пути **и** возможность находить их, используя только локальную информацию.

### Почему именно $r=2$?

* При $r<2$ длинные рёбра **слишком «равномерно дальние»** → много хаоса, сложно систематически приближаться к цели локально.
* При $r>2$ рёбра **слишком локальны** → не хватает «телепортов» между масштабами; поиск вязнет в локальных областях.
* При $r=2$ достигается **баланс масштаба**: вероятность длинного ребра убывает как $d^{-2}$, что согласовано с ростом числа узлов на расстоянии $d$ (порядка $d$ по радиусу и $d^2$ по площади), обеспечивая «равномерное покрытие» масштабов расстояния.

---

## 4) Идея оценки $O((\log n)^2)$ (эскиз)

Разобьём прогресс на **фазы** по расстоянию до цели $t$: фаза $j$ — когда

```math
2^{j} < d(x,t) \le 2^{j+1}.
```

Пусть $B_j={v:\ d(v,t)\le 2^j}$ — «шар» вокруг цели. При $r=2$ можно показать:

1. Вероятность, что из текущего $x$ есть **дальнее ребро** в $B_j$, **не слишком мала** (порядка $1/\log n$), т.к.

   ```math
   \Pr\big((x,v)\in E\big)\ \approx\ \frac{1}{Z}\,d(x,v)^{-2},
   \qquad
   Z=\sum_{u\ne x} d(x,u)^{-2}\ =\ \Theta(\log n).
   ```
2. Следовательно, ожидание числа шагов до выхода из фазы $j$ — $O(\log n)$.
3. Число фаз — $O(\log n)$ (дистанция уменьшается вдвое при переходе фазы).

Суммарно:

```math
\mathbb{E}[T]\ =\ O(\log n)\ \times\ O(\log n)\ =\ O\big((\log n)^2\big).
```

---

## 5) Интуиция через нормировку вероятностей при $r=2$

Нормирующая сумма для $r=2$:

```math
Z=\sum_{u\ne x} d(x,u)^{-2}
\ =\ \Theta(\log n).
```

Тогда для любого «кольца расстояний» $[2^j,2^{j+1}]$ суммарная вероятность «прыжка» туда примерно одинакового масштаба (после учёта числа точек на этом кольце), что и создаёт баланс между **локальными** и **дальними** переходами на всех масштабах.

---

## 6) Практические следствия и связь с NSW/HNSW

* Идея «правильного распределения длинных рёбер» лежит в основе **навигационных графов** (NSW/HNSW):
  смешение **локальных** связей (для точного доулучшения) и **длинных** (для ускоренного глобального сближения).
* Хотя NSW/HNSW не реализуют модель Клейнберга буквально, они **инженерно аппроксимируют** её навигационные свойства, обеспечивая быстрый жадный поиск ближайших соседей.

---

## 7) Короткий чек-лист для ответа

* **Модель:** решётка $n\times n$, локальные рёбра $+$ случайные дальние с вероятностью $\propto d^{-r}$.
* **Алгоритм:** децентрализованный greedy — идём к соседу, ближайшему к цели.
* **Теорема:** при $r=2$ ожидаемое время доставки $O((\log n)^2)$; при $r\ne 2$ — существенно хуже (не навигируемо в том же смысле).
* **Интуиция:** при $r=2$ вероятность длинных рёбер «масштабно сбалансирована» с плотностью узлов по расстоянию.
