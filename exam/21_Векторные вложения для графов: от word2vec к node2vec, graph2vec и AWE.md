# Векторные вложения для графов: мост от word2vec к node2vec, graph2vec и AWE
## База: Word2Vec (контекст $\rightarrow$ смысл)

Гипотеза дистрибутивности: слова, встречающиеся в похожих контекстах, имеют близкие значения.

Цель: обучить плотные векторы фиксированной длины, где семантическая близость отражается геометрической близостью (например, косинусной).

Архитектуры:

Skip-Gram: предсказываем контекст по слову.

CBOW: предсказываем слово по контексту.

Обучение: максимизируем лог-правдоподобие пар «слово–контекст»; на практике используем Negative Sampling:
$
\log \sigma(\mathbf{v}c^\top \mathbf{v}w) + \sum{i=1}^{k}\log \sigma(-\mathbf{v}{n_i}^\top \mathbf{v}_w)
$
где $\mathbf{v}_w$ — вектор слова, $\mathbf{v}c$ — вектор контекстного слова, $\mathbf{v}{n_i}$ — «негативные» образцы.

Ключевой перенос мысли: если суметь сконструировать «контекст» для других объектов (узлов или целых графов), можно применять тот же принцип обучения.

## От слов к узлам: Node2Vec (контекст узла = узлы из обходов)

Аналогия: слово $\leftrightarrow$ узел; предложение $\leftrightarrow$ последовательность узлов, полученная обходом графа.

Идея: сгенерировать много «предложений» (последовательностей узлов) через biased random walks, а затем обучить Skip-Gram + Negative Sampling ровно как в NLP.

Результат: для каждого узла $u$ учим вектор $\mathbf{z}_u \in \mathbb{R}^d$, который сохраняет его локальный контекст и/или роль в структуре.

## От слов к целым документам — и к целым графам: Graph2Vec

Doc2Vec напоминание: добавляем вектор документа $\mathbf{d}$, который участвует в предсказании слов документа.

В частности, PV-DBOW: документ $\rightarrow$ его слова (без явного контекста слов).

Перенос на графы:

слово $\leftrightarrow$ структурный токен (подграф/метка WL),

документ $\leftrightarrow$ граф.

Weisfeiler–Lehman (WL) relabeling:

стартовые метки узлов,

итерируем: новая метка = хеш из текущей метки узла и мультимножества меток соседей,

все метки на всех итерациях — «графовые токены».

Обучение Graph2Vec (PV-DBOW):
$
\sum_{t \in \text{tokens}(G_i)} \log p(t \mid \mathbf{g}_i)
$
где $\mathbf{g}_i$ — вектор графа $G_i$; используется negative sampling.
Итог: один вектор $\mathbf{g}$ на весь граф — удобен для классификации/поиска сходства графов.

## Anonymous Walk Embeddings (AWE): чистая структура без ID

Мотивация: Node2Vec зависит от ID узлов (не переносится между графами), Graph2Vec опирается на метки (или их WL-переобозначение).

Идея: описывать граф распределением анонимных обходов фиксированной длины $l$ — последовательностей, где каждый узел заменён на индекс своего первого появления в обходе.
Пример: $A \to B \to A \to C \to B \Rightarrow 1 \to 2 \to 1 \to 3 \to 2$.

Два режима:

Unsupervised: вектор частот всех анонимных шаблонов длины $l$ (интерпретируемо).

Supervised: обучаем векторы шаблонов ${\mathbf{e}w}$ и представляем граф средним
$
\mathbf{g}=\frac{1}{N}\sum{i=1}^{N}\mathbf{e}_{w_i}
$
(компактно, адаптивно к задаче).
