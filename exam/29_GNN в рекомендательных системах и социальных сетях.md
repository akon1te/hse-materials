# GNN в рекомендательных системах и социальных сетях

## Рекомендации (user–item и multi-relational графы)

Типичный граф: двудольный $U!-!I$ (пользователи–товары) + опционально связи “user–user”, “item–item”, знаниевые графы (KG) и атрибуты.
Задачи: link prediction / ranking (какой товар пользователь купит/посмотрит), CTR, топ-K рекомендации, cold-start.

Как GNN помогают:

Коллаборативный сигнал через граф. Агрегация соседей распространяет предпочтения: пользователь наследует сигналы от купленных/лайкнутых товаров и наоборот.

Многошаговый контекст. Несколько слоёв дают доступ к “соседям второго/третьего порядка” (покупатели похожих товаров, ко-покупки и т.д.).

Индуктивность. С признаками (тексты, категории, профили) GNN обобщают на новых пользователей/товары.

Гетерогенность и мультирелейшн. R-GCN/Graph Transformers учитывают разные типы рёбер (просмотр, лайк, корзина, покупка; разные отношения в KG).

Масштабируемость. Используют семплирование соседей (GraphSAGE-style), упрощённые свёртки (например, “лайт” варианты с чистой пропагацией без лишних нелинейностей), частичный offline-прекомпьют.

Паттерны/архитектуры на практике:

GCN-подобные CF-модели (идея: многослойная пропагация эмбеддингов пользователей/товаров с нормировкой; иногда без нелинейностей для простоты и скорости).

GraphSAGE-семплирование для мини-батчей на больших графах (пины, каталоги, медиатека).

GAT/attention — когда связи неоднородны по важности (например, недавние взаимодействия важнее старых).

KG-aware рекомендации (R-GCN/CompGCN/Graph Transformers на знаниевых графах) — улучшают explainability и cold-start за счёт семантики.

Метрики: HR@K, NDCG@K, MRR, AUC, CTR.
Инженерные нюансы: негативное сэмплирование, temporal decay, хранение и периодическое обновление эмбеддингов, approximate nearest neighbors для онлайн-ретрива.

## Социальные сети

Графы: user–user (friend/follow), user–content, content–content (reshare/quote/reply), heterogeneous (много типов узлов/рёбер), динамические/временные.

Задачи и роль GNN:

Рекомендации друзей/подписок и контента (link prediction, feed ranking):
GNN агрегируют сигналы интересов через социальные связи и взаимодействия с постами, учитывая многошаговые зависимости и контентные признаки (текст/изображения как node features).

Коммьюнити-детекция и сегментация:
Эмбеддинги узлов кластеризуются для выявления сообществ/тем.

Моделирование диффузии (виральность, прогноз охвата):
Используют спатио-темпоральные GNN/attention, чтобы захватывать пути распространения.

Модерация/безопасность:
Анти-спам, анти-фрод, бот-нетworks — GNN хорошо ловят структурные закономерности и координации, которые сложно подделать только контентом.

Рекомендации в мультиграфах:
Совмещение user–user, user–item и KG (например, автор–тема–сообщество) повышает релевантность и объяснимость.

Моделирование времени/масштаба:

Temporal/streaming GNN (разделение на срезы, event-based updates, edge recency).

Sampling/индексирование для огромных графов (layer-wise или node-wise sampling, neighbor caching).

Гетерогенные GNN с типами узлов/рёбер и отдельными параметрами/каналами внимания.

Практические приёмы:

Feature fusion: текст/изображение → encoder → узловые/рёберные фичи для GNN.

Two-tower/многоступенчатые пайплайны: GNN-эмбеддинги для ретрива, дальше — переранжирование (GBDT/Transformer).

Fairness/robustness: регуляризация, дебайсинг, adversarial-стресстесты.
