# Как работает механизм внимания в GAT (Graph Attention Networks)

## 1) Что подаём на слой

* На вход слоя $l$ даны представления узлов: $h_v^{(l)} \in \mathbb{R}^{D_l}$ для всех $v$.
* Рассматриваем соседей $u \in N(v)$; часто включаем и сам узел $v$ (self-loop), то есть агрегируем по $N(v)\cup{v}$.

## 2) Линейное преобразование признаков

Все узловые векторы сначала проецируются общей обучаемой матрицей:

* $\Theta \in \mathbb{R}^{D' \times D_l}$ — «внутренняя» размерность внимания $D'$ — гиперпараметр.
* Преобразованные векторы: $\Theta h_v^{(l)} \in \mathbb{R}^{D'}$.

## 3) Подсчёт «сырой важности» (energy) для пары $(v,u)$

Для каждой пары соседей $(v,u)$ вычисляется скалярная *энергия внимания* $e_{vu}$:
$
e_{vu}=\operatorname{LeakyReLU}!\big(a^\top ,[,\Theta h_v^{(l)} \ \Vert\ \Theta h_u^{(l)},]\big),
$
где:

* $a \in \mathbb{R}^{2D'}$ — обучаемый вектор внимания,
* $\Vert$ — конкатенация,
* $\operatorname{LeakyReLU}$ — с небольшим отрицательным наклоном (в конспекте упомянуто типично $0.2$).

Интерпретация: $e_{vu}$ — насколько «важен» сосед $u$ для обновления узла $v$ на текущем слое.

## 4) Нормализация важностей по окрестности через softmax

Чтобы сделать веса сопоставимыми и интерпретируемыми, применяем softmax по всем $u \in N(v)\cup{v}$:
$
\alpha_{vu}=\text{softmax}*u(e*{vu})=\frac{\exp(e_{vu})}{\sum_{k\in N(v)\cup{v}}\exp(e_{vk})}.
$
Здесь $\sum_{u}\alpha_{vu}=1$ для фиксированного $v$ — это распределение внимания в окрестности $v$.

> Замечание: нормализация выполняется **локально** по соседям каждого $v$, что делает механизм пермутационно-инвариантным внутри окрестности и учитывающим только структуру $N(v)$.

## 5) Взвешенная агрегация и нелинейность

Нормализованные коэффициенты внимания используются как веса при агрегировании трансформированных соседей:
$
h_v^{(l+1)}=\sigma!\Big(\sum_{u\in N(v)\cup{v}} \alpha_{vu},\Theta h_u^{(l)}\Big),
$
где $\sigma(\cdot)$ — нелинейная активация (например, ReLU; в конспекте не фиксирована).

* В отличие от равномерного усреднения (как в базовой схеме), вклад каждого соседа **обучается** через $\alpha_{vu}$.
* Self-loop ($u=v$) позволяет узлу «протащить» собственную информацию вперёд вместе с соседями.

## 6) Многоголовое внимание (Multi-Head)

Чтобы повысить выразительность и стабильность:

* Используем $K$ «голов» внимания с **независимыми** параметрами $(\Theta^k,a^k)$.
* Для скрытых слоёв выходы **конкатенируются**:
  $
  h_v^{(l+1)}=\big\Vert_{k=1}^{K} \ \sigma!\Big(\sum_{u\in N(v)\cup{v}} \alpha_{vu}^{k},\Theta^{k} h_u^{(l)}\Big).
  $
* Для выходного слоя (классификация/регрессия) часто делают **усреднение** по головам (в конспекте это сформулировано как «обычно конкатенация для скрытых слоёв, усреднение для выходного»).

## 7) Где тут «message passing»

С точки зрения MPNN (см. ваш раздел 6):

* **Сообщение** от $u$ к $v$: $m_{vu}^{(l)}=\alpha_{vu},\Theta h_u^{(l)}$.
* **Агрегация**: сумма по $u\in N(v)\cup{v}$.
* **Обновление**: применение $\sigma(\cdot)$ к агрегату даёт $h_v^{(l+1)}$.

## 8) Интуиция и практический смысл

* **Зачем внимание?** Вместо одинакового вклада всех соседей, GAT **динамически учится** выделять наиболее релевантных для задачи соседей (например, тех, чьи признаки особенно информативны).
* **Локальность и инвариантность:** взвешивание происходит в пределах окрестности, softmax — по соседям, что сохраняет пермутационную инвариантность и локальную природу свёртки на графе.
* **Гибкость:** разные «головы» могут улавливать различные аспекты зависимости в окрестности (разные «типы» соседства), а затем объединяться.

### Короткий псевдокод шага GAT-слоя (одна голова, по конспекту)

1. $z_v \leftarrow \Theta h_v^{(l)}$ для всех $v$
2. Для каждого ребра $(v,u)$ (и self-loop): $e_{vu}\leftarrow \operatorname{LeakyReLU}!\big(a^\top [z_v \Vert z_u]\big)$
3. Для каждого $v$: $\alpha_{vu}\leftarrow \dfrac{\exp(e_{vu})}{\sum_{k\in N(v)\cup{v}}\exp(e_{vk})}$
4. $h_v^{(l+1)} \leftarrow \sigma!\big(\sum_{u\in N(v)\cup{v}} \alpha_{vu}, z_u\big)$

(Для $K$ голов — повторить пункты 1–4 с $(\Theta^k,a^k)$ и затем объединить головы конкатенацией или усреднением, как описано выше.)
